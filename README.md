A haiku (5-7-5) about debugging, for the [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605) bounty on make.fun.

```
off by one again
the loop ends one short each time
zero-indexed pain
```

`main.py` (Python 3, stdlib only) writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` and self-checks the 5-7-5 syllable counts before writing.
